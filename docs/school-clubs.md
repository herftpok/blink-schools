# Клубы и группы

Прототип: `/#clubs` — развёртка экранов слева, кликабельный прототип справа.

## Как устроено

- клуб создаёт любой участник школы: аватар и название до 24 символов;
  создатель сразу в клубе;
- вступить может любой, прямо из списка клубов или с экрана клуба; выйти —
  с экрана клуба;
- у клуба есть чат, его видят и пишут в нём только участники; для остальных
  вход в чат закрыт замком;
- в универе клубами становятся факультеты и кружки, в школе — клубы по
  интересам; механика одна.

## Экраны

| Экран | Что важно |
|-------|-----------|
| хаб · точка входа | вход — вкладка «клубы» рядом со «студентами» |
| клубы | тёмная кнопка «создать клуб», список клубов с аватаром, лицами и числом участников, «вступить» в строке |
| клуб · не участник | аватар, название, число участников, чат с замком, список участников, белая «вступить» |
| клуб · участник | создатель первым с подписью «создатель» вместо старсов и друзей; чат открыт; в списке клубов «выйти» в стиле «отменить», внизу экрана тёмная «выйти из клуба» |
| чат клуба | заголовок «только для участников», пузыри как в чатах школы |
| новый клуб | аватар с загрузкой, название со счётчиком |
