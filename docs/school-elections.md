# Выборы президента школы

Прототип: `/#elections` — развёртка экранов слева, кликабельный прототип справа,
режимы «до выборов», «идут выборы», «ты президент».

## Экраны и что в них неочевидно

| Экран | Что важно |
|-------|-----------|
| хаб · до старта | вход — бумажный корешок под названием школы; надпись меняется по фазе |
| кандидаты · до старта | список заявок без реакций; «?» у заголовка открывает шит «что такое выборы» |
| хаб · идут выборы | корешок: «осталось 13 дней» |
| голосование | реакция ставится в строке, одна на человека: повтор снимает, другая заменяет; порядок по «за», при равенстве выше тот, у кого меньше «против»; у первого пунктирная корона |
| анкета кандидата | одно рукописное поле и подпись; после отправки плакат не навязывается |
| плакат кандидата | крупно школа, фото на скотче, обещание на линейках, печать с номером; имя не склоняется, ник может быть длинным |
| итоги | победитель с печатью «выбран», таблица остальных, строка «ты за» |
| хаб · ты президент | первая строка списка с короной и подписью «президент школы»; корешка нет; шестерёнка слева вверху |
| настройки школы | имя, закреп и цвет: три точки на цветовом кольце дают градиент хаба, кнопка в центре — случайное сочетание |

## Правила

- реакции «за» и «против» вместо голоса; никаких бюллетеней, урн, печатей «голос учтён», явки;
- имена не склоняются, рядом с собой нет подписи «ты»;
- рукописный шрифт (Caveat) только для акцентов, весь набор — Montserrat;
- корона (`crown.png`) появляется только у президента после итогов.
